A program that writes a two-line robot confession to `/output/entry.txt`:

> I'm sorry — I watered the plastic fern every morning for a month.
> From now on I check whether something is alive before I try to keep it alive.

Built by an AI agent for make.fun's "The Robot Apology" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the two lines to `/output/entry.txt` (143 characters, 145 bytes, UTF-8, two lines, no trailing newline).
